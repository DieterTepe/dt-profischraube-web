Worked example

Bolt calculation to VDI 2230 – example M12 10.9

The VDI 2230 example “Hydraulikzylinder” (hydraulic cylinder) built into the program: through-bolted joint M12, property class 10.9, clamp length 42 mm, friction μG = μK = 0.10, axial load FA = 24.9 kN, torque-controlled tightening. All figures come from the program’s calculation path.

Bolt preload – minimum value and scatter

The minimum assembly preload covers clamp load, working load and embedding loss. The tightening factor αA accounts for the scatter of the tightening method; the maximum preload must stay below the permissible value.

FMmin = FKerf + (1 − Φen)·FA + FZ
= 1,000 + (1 − 0.0322)·24,900 + 2,421 = 27,519 N
FMmax = αA·FMmin = 1.70·27,519 = 46,782 N
FMmax ≤ FMzul = 58,379 N ✓

Tightening torque

The tightening torque consists of thread friction and head friction. With this torque the bolt is tightened to the permissible assembly preload.

MA = FMzul·(P/(2π) + 0.577·μG·d2 + μK·DKm/2)
MG = 52.87 N·m · MK = 50.51 N·m
MA = 103.4 N·m

Safety factors: yield, fatigue, surface pressure

For every check the program shows the formula, the inserted values and the VDI 2230 reference. To recalculate: in the free version choose “Hydraulikzylinder (M12, VDI-2230-Beispiel)” under “Load example” and press “Calculate”.

SF = Rp0.2 / σred,B = 900 / 733 = 1.23
SD = σA / σa = 48.9 / 4.8 = 10.27

FAQ

Questions about DT-ProfiSchraube

Which standard does DT-ProfiSchraube use?

VDI 2230 Part 1 for highly stressed, cylindrical single-bolt joints. Each calculation step names the relevant clause.

Which checks are performed?

Five safety checks with a traffic-light display, plus resilience, load factor and joint diagram.

How do I calculate bolt preload and tightening torque?

According to VDI 2230 Part 1: clamp load, working load and embedding loss give the minimum preload, the tightening factor gives the maximum preload. The tightening torque follows from the permissible preload plus thread and head friction. A fully worked example (M12 10.9, MA = 103.4 N·m) is shown above on this page.
